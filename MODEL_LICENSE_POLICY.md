# Zerith VA model-weight licensing policy

This source repository contains **no model checkpoints or weights**. Its
[Apache-2.0 license](LICENSE) covers Zerith-authored code and documentation as
described in [LICENSE_POLICY.md](LICENSE_POLICY.md); it does not license model
weights, training data, text banks, or third-party assets.

Weights will be published separately on Hugging Face. The planned
[model repository link](https://huggingface.co/REPLACE_WITH_ORG/Zerith-VA)
is a placeholder, not an available download. Replace it when publishing the
weights, and include the permissions and binding license terms with each
model/version on Hugging Face.

For each future release of a model checkpoint owned and licensable by Zerith
Robotics, Zerith will publish separate terms with that checkpoint. The intended
terms permit only the uses expressly granted in the model release and require
a **separate written commercial license from Zerith Robotics** before
commercial use of the checkpoint or weights derived from it, including
fine-tuned or otherwise modified versions. A code license or access to this
repository does not supply that commercial model license.

This document is a release policy, not a license grant for any checkpoint.
The actual model terms must identify the model/version, permitted noncommercial
uses, the scope of derivatives, redistribution conditions, and a licensing
contact or process. Terms for third-party base models, assets, data and
dependencies still apply independently. Complete that review before releasing
any weights or offering commercial permissions.
