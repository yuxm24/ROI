# Changelog

- ZWAM policy inference with three RGB views, task text embeddings and H1 state.

- Interactive startup and pause/replan recovery for IK and target failures.
- Unified CLI with offline configuration diagnostics and start/stop scripts.
- Python packaging, Docker recipe, English/Chinese setup guides and offline tests.
